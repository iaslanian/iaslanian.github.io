Research

Parents don’t need more advice. They need one thing to do together tonight

Parent interviews and therapist consults kept pointing to the same patterns:

Mid-moment – parents open the app during a hard moment, not out of curiosity.
Doing over reading – reading feels like progress; doing one small thing is progress.
Ten minutes – what survives a tired evening is ten minutes, not a course.
Shared progress – it’s easier to keep going when the child can see progress too.
Solution

One daily plan, every piece labeled by who does it

I rebuilt the product around one plan for one child, split into three tiers so a parent, a partner or a grandparent can pick up the same evening:

I do – a few quiet minutes for the parent alone.
We do – a short game or activity to do with the child.
Extra – tools and tips to go deeper, whenever there’s energy.

Every therapist script became a single sentence a parent can say out loud in the next ten seconds.

Foundations

One token structure from Figma to code

Tokens for color, typography, spacing, radii and heights, shared between Figma and code in three layers:

Primitive – raw values.
Semantic – meaning-based tokens.
Component – overrides only when needed.

Setting it up took time, but it paid off: dark mode and multi-brand theming later took days instead of months.

Iconography

About 80 custom icons on one grid

The old set had no shared style. We took Material Icons (rounded) as a base and drew the domain-specific icons by hand on the same grid. Move the cursor across the image to compare before and after.

Systemic fixes

Good UX built in by default

Instead of proposing isolated fixes that get deprioritized, I built them into the foundation, so teams didn’t have to opt in:

Accessibility – text and surface tokens pass WCAG AA contrast.
Touch targets – every interactive element is at least 44px.
Safer actions – proper destructive states, missing before.
Workflow

From Figma to production

With two front-end developers, we connected the system to Storybook and Widgetbook through Supernova – the single source of truth for engineering. Later, Figma Code Connect and MCP made it usable in AI-assisted code generation. My part: naming aligned with code and variants matched to component props.
